# مهاجرت Dynamic Schema دبیرخانه - نسخه 4

این نسخه DatabaseHelper را از version 3 به version 4 می‌برد.

## دیتابیس فعلی
اگر دیتابیس قبلی نسخه 3 باشد:

- تمام ستون‌های فعلی `daftare_andicator` حفظ می‌شوند.
- جدول `record_schema` ساخته می‌شود.
- 14 فیلد فعلی داخل Schema ثبت می‌شوند.
- چینش فعلی فرم، تنظیمات جستجوی فعلی و تنظیمات آماری فعلی ثبت می‌شوند.
- هیچ رکوردی تبدیل یا حذف نمی‌شود.

## نصب جدید
در نصب جدید جدول `daftare_andicator` ابتدا فقط با ستون `Shomare_Radif` ساخته می‌شود. سپس کاربر در صفحه «راه‌اندازی دبیرخانه» فیلدها را تعریف می‌کند. برای هر فیلد جدید، یک ستون واقعی SQLite با `ALTER TABLE ... ADD COLUMN` ساخته می‌شود.

## محل تنظیمات
تنظیمات ساختار در جدول زیر ذخیره می‌شود:

`record_schema`

این جدول شامل `fields_json`، `layout_json`، `search_json` و `stats_json` است؛ بنابراین فایل دیتابیس و Backup به تنهایی برای انتقال ساختار کافی است.

## نکته مهم
غیرفعال کردن فیلد، ستون و داده‌های قبلی را حذف نمی‌کند. این کار عمداً برای جلوگیری از از دست رفتن داده‌ها در Restore و نسخه‌های قدیمی انجام شده است.
