تغییرات هماهنگ‌سازی دبیرخانه
============================

فایل‌های داخل این بسته را جایگزین فایل‌های همنام پروژه کنید.

فایل جدید:
lib/services/sync/sync_discovery_service.dart

فایل‌های تغییرکرده:
lib/services/sync/sync_service.dart
lib/services/sync/sync_network_client.dart
lib/ui/dialogs/backup_restore_dialog.dart

نحوه کار:
- دستگاه اصلی روی شبکه محلی خودکار معرفی می‌شود.
- دستگاه دوم می‌تواند بدون وارد کردن IP، دستگاه مادر را پیدا کند.
- IP پیدا شده در تنظیمات ذخیره می‌شود و Sync HTTP فعلی ادامه پیدا می‌کند.
- کلید امنیتی فعلی حذف نشده و همچنان برای احراز هویت لازم است.
- برای اولین اتصال، روی دستگاه مادر «کپی کد اتصال» و روی دستگاه دوم «اعمال کد و اتصال» را یک بار انجام دهید. بعد از آن IP به‌صورت خودکار کشف می‌شود و نیازی به وارد کردن دستی IP نیست.
- Discovery روی UDP پورت 39422 انجام می‌شود و Sync روی پورت HTTP فعلی (پیش‌فرض 39421) باقی می‌ماند.

اگر دستگاه‌ها به یک Wi-Fi وصل هستند ولی چیزی پیدا نمی‌شود، گزینه AP Isolation / Client Isolation / Wireless Isolation مودم را بررسی کنید و در صورت فعال بودن خاموش کنید. فایروال ویندوز نیز ممکن است اولین بار اجازه ارتباط شبکه را درخواست کند.
